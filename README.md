# Маска кожных покровов лица по ключевым точкам dlib

Программа создаёт изображение-маску кожных покровов лица на основе ключевых точек лица.  
Входное изображение обрабатывается с помощью `dlib`: сначала находится лицо, затем модель `shape_predictor_68_face_landmarks.dat` определяет 68 ключевых точек. По этим точкам строится область лица, из неё исключаются глаза, брови и рот, после чего результат сохраняется в файл того же размера и формата, что и исходное изображение.

## Возможности

- Поиск одного или нескольких лиц на изображении.
- Построение маски лица по 68 ключевым точкам.
- Исключение глаз, бровей и рта из итоговой области.
- Поддержка изображений `.jpg`, `.jpeg`, `.png`.
- Корректная работа с путями, содержащими русские символы.
- Автоматическое создание выходного файла с суффиксом `_skin`.

## Требования

- Python 3.10–3.12
- OpenCV
- dlib
- NumPy
- Файл модели `shape_predictor_68_face_landmarks.dat`

## Установка

```bash
pip install opencv-python numpy dlib
```

Если `dlib` не устанавливается через `pip`, нужно установить CMake и инструменты сборки Visual Studio C++ Build Tools, либо использовать заранее собранную версию `dlib` под вашу версию Python.

## Файл модели landmarks

Файл `shape_predictor_68_face_landmarks.dat` не устанавливается вместе с `dlib`.  
Его нужно скачать отдельно и положить рядом со скриптом.

По умолчанию программа ищет файл с именем:

```text
shape_predictor_68_face_landmarks.dat
```

в той же папке, где запускается скрипт.

Также можно передать путь к модели вручную через параметр `--predictor`.

## Запуск

Пример запуска:

```bash
python face_mask.py image.jpg
```

В результате будет создан файл:

```text
image_skin.jpg
```

Пример запуска с указанием выходного файла:

```bash
python face_mask.py image.jpg -o result.png
```

Пример запуска с указанием пути к модели:

```bash
python face_mask.py image.jpg -p shape_predictor_68_face_landmarks.dat
```

## Принцип работы

1. Изображение считывается через OpenCV.
2. `dlib.get_frontal_face_detector()` находит лица на изображении.
3. `dlib.shape_predictor()` определяет 68 ключевых точек лица.
4. По точкам нижней челюсти и верхней части лица строится основная область лица.
5. Области глаз, бровей и рта исключаются из маски.
6. Для цветных изображений дополнительно применяется адаптивная фильтрация по цвету кожи.
7. Итоговая маска применяется к исходному изображению.
8. Результат сохраняется в файл.

## Ограничения

Метод зависит от качества найденных ключевых точек. На сложных изображениях, при сильном повороте головы, плохом освещении или частично закрытом лице результат может быть менее точным. Для корректной работы требуется, чтобы лицо было достаточно хорошо видно на изображении.

Входное изображение:

```text
image.jpg
```

Запуск:

```bash
python face_mask.py image.jpg
```

